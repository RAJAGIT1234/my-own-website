## 🌟 Architecture & Key Highlights

- **Event-Driven Architecture**: High-scale event streaming with Apache Kafka, DLQ, Idempotent Consumers, and Saga Pattern handling 2.4M+ daily messages.
- **Microservices & Low Latency**: Java 17/21 Virtual Threads, Spring Boot 3.x, and multi-tier Redis caching achieving p99 latency reduction from 420ms to 75ms.
- **Enterprise Security & Observability**: OAuth 2.0 / JWT perimeter gates, Keycloak IAM, and distributed telemetry with Prometheus & Grafana.
- **AI-Augmented Engineering**: Cursor IDE, Claude 3.5 Sonnet, and GitHub Copilot integrated into backend development workflows with strict OWASP & memory safety verification.
- **Recruiter & Visitor Pass**: Instant frictionless guest pass system for recruiters and engineering leaders with personalized metrics dashboard.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation & Run

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd my-own-website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
